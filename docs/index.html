Hulp bij streepje

Voor Scouting Jan Willem Friso

streepje houdt bij wie op een evenement wat gedronken en gegeten heeft, en wie er aan het eind nog moet betalen. Eén tik per bestelling, ook als er geen bereik is.

Nog nooit mee gewerkt? Begin bij Achter de bar met streepje — zes stappen met schermen erbij, van evenement klaarzetten tot afrekenen.

Kom je er niet uit? Mail meco@scoutingjwf.nl. Schrijf erbij welke telefoon je gebruikt en wat er op het scherm stond, dan is het meestal zo gevonden.

Veelgestelde vragen

Ik ben de correctiecode kwijt

Die code staat alleen op de telefoon waarop hij is ingesteld en is nergens anders na te kijken — ook niet door ons. Zonder de code kun je niets meer weghalen in dat evenement. Wat er geturfd is blijft gewoon staan en je kunt het evenement nog steeds exporteren; maak daarna een nieuw evenement aan met een code die je onthoudt.

De andere telefoon kan de code niet scannen

Onderaan het scherm Delen staat ook een code van zes tekens. Die kun je op de andere telefoon intypen bij Deelnemen. Werkt dat ook niet, controleer dan of beide telefoons internet hebben; delen heeft verbinding nodig, turven niet.

Er staat "Offline" terwijl ik wel internet heb

Turf gewoon door. Alles wordt op de telefoon bewaard en gaat er vanzelf uit zodra er weer verbinding is. Op het scherm Delen zie je hoeveel bestellingen er nog klaarstaan.

Ik heb per ongeluk te veel geturfd

Een turf weghalen kan alleen op de telefoon die het evenement deelt, en alleen met de correctiecode. Dat is met opzet: een turf weghalen haalt geld van iemands rekening af. Elke correctie blijft zichtbaar bij de persoon, bij de totalen en in de export.

Hoe krijg ik de lijst naar de penningmeester?

Bij Totalen staat Exporteren. Kies CSV voor een bestand dat in Excel opengaat, of de korte samenvatting om in de groepsapp te plakken.

Hoe verwijder ik de gegevens weer?

Op de telefoon die deelt: Delen → Gedeelde lijst verwijderen, met de correctiecode. Namen en turfjes worden dan van de server gewist, ook voor de andere telefoons. Elke telefoon houdt zijn eigen kopie, dus je raakt niets kwijt van wat er al geturfd is. Wil je die kopie ook weg, verwijder dan het evenement op de telefoon zelf.

Werkt de app zonder account?

Ja. Er is geen account en er valt niets in te loggen. Zonder delen verlaat er geen enkel gegeven de telefoon.
